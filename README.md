# Rock Paper Scissors Pro

A high-performance, cross-platform Rock Paper Scissors application. This project delivers a competitive "Versus" experience with a persistent HUD and an ergonomically optimized interface for both desktop and mobile environments.

---

## 🚀 Live Demo
**[Test the Game Live Here](https://rpcvishnu.netlify.app/)**

---

## 🛠️ Technical Features
* **Dynamic HUD:** Real-time score tracking with a persistent status interface.
* **Cross-Device Architecture:** Fully responsive engine that adapts between desktop and mobile layouts.
* **Optimized Logic:** Low-latency event handling for competitive gameplay.
* **High-Fidelity Assets:** Class-based styling for consistent rendering of Rock, Paper, and Scissors icons.

---

## 📂 Project Structure
* `index.html` - Semantic structure and game containers.
* `rock.css` - Advanced responsive styling and HUD layout.
* `rock.js` - Game mechanics, AI logic, and score management.

---

## 🕹️ How to Play
1. **Select Weapon:** Choose Rock, Paper, or Scissors from the main stage.
2. **Battle:** The system calculates the result against the computer AI.
3. **Track Progress:** View live updates in the synchronized scoreboard HUD.
4. **Replay:** Use the integrated action menu to reset the session.
